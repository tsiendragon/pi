# Agent write-path probe

Created by an automation agent to verify outbound write access to GitHub from a host
whose egress proxy blocks `git-receive-pack` (standard `git push` returns HTTP 502).
The write used api.github.com Git Data API: blob -> tree -> commit -> ref.
